# Tài liệu tham khảo

Các tài liệu dưới đây là nguồn tài liệu chính thức nên được kiểm tra theo đúng phiên bản phần mềm sử dụng trong thực nghiệm. Khi viết báo cáo, trích dẫn theo quy chuẩn mà giảng viên yêu cầu.

## MySQL

1. MySQL 8.4 Reference Manual, *Optimization and Indexes*. https://dev.mysql.com/doc/refman/8.4/en/optimization-indexes.html
2. MySQL 8.4 Reference Manual, *InnoDB Index Types*. https://dev.mysql.com/doc/refman/8.4/en/innodb-index-types.html
3. MySQL 8.4 Reference Manual, *EXPLAIN Statement*. https://dev.mysql.com/doc/refman/8.4/en/explain.html
4. MySQL 8.4 Reference Manual, *InnoDB and the ACID Model / Index organization*. https://dev.mysql.com/doc/refman/8.4/en/innodb-introduction.html

## MongoDB

5. MongoDB Manual, *Indexes*. https://www.mongodb.com/docs/manual/indexes/
6. MongoDB Manual, *Index Types*. https://www.mongodb.com/docs/manual/indexes/index-types/
7. MongoDB Manual, *Compound Indexes*. https://www.mongodb.com/docs/manual/core/indexes/index-types/index-compound/
8. MongoDB Manual, *Explain Results*. https://www.mongodb.com/docs/manual/reference/explain-results/
9. MongoDB Manual, *Analyze Query Plan*. https://www.mongodb.com/docs/manual/tutorial/analyze-query-plan/

## Ghi chú kiểm chứng

- Ghi phiên bản tài liệu tương ứng phiên bản DBMS cài đặt.
- Với nội dung phụ thuộc phiên bản, trích dẫn trang tài liệu cụ thể và ngày truy cập.
- Không dùng tài liệu marketing làm bằng chứng duy nhất cho kết luận benchmark.
